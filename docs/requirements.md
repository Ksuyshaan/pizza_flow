# Requirements

Created: October 1, 2026 2:27 PM

### Главные требования:

- Авторизация и разграничение интерфейса по ролям.
- Главное окно с боковым/верхним меню и Dashboard.
- Таблицы данных с поиском, фильтрацией, сортировкой и пагинацией либо разумной загрузкой данных.
- Формы создания и редактирования с проверкой обязательных полей и понятными сообщениями об ошибках.
- Диалог подтверждения опасных действий: удаление, отмена, списание и т.п.
- Минимум 2 визуальных элемента аналитики: графики, диаграммы, KPI-карточки.
- Экспорт реальных данных приложения в Excel и Word через Apache POI.
- Пользователь не должен вводить SQL, JSON или команды в консоль для обычной работы.

### Архитектура и обязательные технологии

| Компонент | Требования | Ответственный |
| --- | --- | --- |
| GUI | JavaFX; допускается FXML + Scene Builder | Вместе |
| Логика  | Spring Boot, Service-layer | Вместе |
| Данные  | Spring Data JPA / Hibernate | Алина |
| БД | PostgreSQL or MySQL | Алина |
| Модель | Не менее 8 сущностей, связи 1:N / N:M, ограничения | Вместе |

### Обязательная бизнес-логика

- Запрет недопустимых переходов статусов.
- Автоматический расчет суммы, скидки и доставки.
- История каждого изменения статуса.
- Алгоритм назначения/очереди курьеров как усложнение.

### Требования к визуалу

- Единый современный стиль всех экранов.
- Главное меню и понятная навигация без запуска отдельных классов вручную.
- Таблицы должны иметь действия «Добавить», «Изменить», «Удалить/Отменить», поиск и фильтры там, где это логично.
- Ошибки показывать через Alert/Dialog рядом с пользовательским действием.
- Dashboard должен строиться из данных БД, а не из заранее прописанных чисел.
