# Матрица ролей и прав доступа PizzaFlow

## 1. Роли в системе
Система поддерживает 5 ролей пользователей:
1. **CUSTOMER** — Клиент ресторана (гость/зарегистрированный покупатель).
2. **COOK** — Повар / Сотрудник кухни.
3. **COURIER** — Курьер службы доставки.
4. **MANAGER** — Управляющий рестораном / Администратор смены.
5. **ADMIN** — Системный администратор (полный доступ).
